# Liquid Glass Hub - منصة التواصل والدفع الذكية

منصة ويب تفاعلية حديثة بتصميم زجاجي سائل فخم (**Liquid Glassmorphism**) مع مؤثرات حركة وانكسار ضوئي متقدمة، مخصصة لربط حسابات التواصل الاجتماعي (Facebook, WhatsApp, TikTok) وبوابات الدفع الإلكتروني المباشر.

---

## 🌟 المميزات الرئيسية (Features)

- **تصميم زجاجي سائل فاخر (Liquid Glass UI):** أحدث صيحات الـ Glassmorphism مع تأثيرات انكسار ضوئي (Refraction) وظلال عميقة وتدرجات لونية ديناميكية.
- **شريط تنقل مائع (Liquid Spring Navbar):** مؤشر تفاعلي يتدفق بين التبويبات بسلاسة عند الضغط والتنقل.
- **أقسام متكاملة لكل قناة تواصل:**
  - **الرئيسية (Home):** بطاقات سريعة، إحصائيات، وموجز للميزات.
  - **فيسبوك (Facebook):** بطاقة بروفايل مخصصة مع زر متابعة وتوجيه مباشر.
  - **واتساب (WhatsApp):** بدء محادثة فورية مع رسائل جاهزة وتفاعل مباشر.
  - **تيك توك (TikTok):** شاشات عرض المحتوى ومتابعة الحساب.
  - **الدفع والتحويل (Pay):** واجهة دفع وتحويل أموال متقدمة مع نسخ أرقام الحسابات ورموز QR وإشعارات تأكيد سريعة.
- **دعم كامل للغة العربية والإنجليزية (RTL First):** خط "Cairo" المعتمد وتنسيق مريح لجميع أحجام الشاشات (الهواتف، الأجهزة اللوحية، والشاشات الكبيرة).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **React 19** & **TypeScript**
- **Vite 8** (بيئة تطوير فائقة السرعة)
- **Tailwind CSS v4** (أحدث محرك للتنسيق)
- **Motion / Framer Motion** (تأثيرات حركة مائعة وانتقالات سلسة)
- **Lucide Icons** (أيقونات فيكتور حديثة)

## 🚀 طريقة التشغيل محلياً (Getting Started)

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث)
- مدير الحزم `npm` أو `pnpm` أو `bun`

### 2. تثبيت الحزم
```bash
npm install
```

### 3. تشغيل خادم التطوير (Local Dev Server)
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000` أو الرابط الموضح في التيرمينال.

### 4. بناء المشروع للإنتاج (Production Build)
```bash
npm run build
```
سيتم إنشاء ملفات الإنتاج الجاهزة في مجلد `dist/`.

## 📦 كيفية رفع المشروع إلى GitHub (Push to GitHub)

إذا كنت تريد رفع هذا المشروع إلى مستودع جديد على حسابك في GitHub:

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في [GitHub](https://github.com/new) وليكن باسم `liquid-glass-hub`.
2. انسخ رابط المستودع (مثال: `https://github.com/YOUR_USERNAME/liquid-glass-hub.git`).
3. نفذ الأوامر التالية في مجلد المشروع:

```bash
git init
git add .
git commit -m "Initial commit: Liquid Glass Hub"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/liquid-glass-hub.git
git push -u origin main
```
